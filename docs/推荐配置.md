# 推荐配置：工作日的两班制天气推送

一句话：**早上 8 点一份全量日报，晚上 21:30 一份不含实况的复盘；只在上班时段盯雨雪和灾害预警；
每天 21:00 对一次额度。** 全部工作日生效，周末和法定假日不打扰。

> 本文的坐标、地点名都是占位示例（`39.90,116.40`、`公司`），照抄时换成自己的即可。
> 坐标顺序固定「**纬度,经度**」，度分秒也能直接粘（`39°13'53",117°8'2"`）。

## 一、这套配置在做什么

| 项目 | 设置 | 何时生效 |
| --- | --- | --- |
| 天气推送 ① | 每天 08:00，全部内容（实况 + 今天/明天/后天/大后天 + 日出日落 + 空气） | 仅工作日 |
| 天气推送 ② | 每天 21:30，全部除实况（去掉当下温度，留着预报和空气） | 仅工作日 |
| 雨雪提醒 | 开；时段 08:00-12:00、13:00-21:30；开始/结束都提醒；提前 10 分钟；轮询 30 分钟 | 仅工作日 |
| 灾害预警 | 开；时段同上；轮询 60 分钟；黄色及以上；等级升降都再推 | 仅工作日 |
| 额度推送 | 每天 21:00，含当天与前一天用量 | 仅工作日 |

早上要出门，所以 8:00 给全量；晚上不看实时温度，只要明天穿什么，所以 21:30 去掉实况。
雨雪和预警只在你可能在户外的时间段盯——半夜下雨不需要叫醒你。

## 二、照抄的命令

### 0. 先配 key（只需一次）

**推荐用系统默认 key**：WebUI → 插件 → 和风天气 → 配置，填 `iss / sub / kid / host / 私钥`，
点「保存并关闭」，**不用重载**。核对：

```
/qweather key
```

看到 `系统默认 key` + 五项都有值就对了。私钥必须显示「已载入」，显示「解析失败」说明 PEM 不完整。

> 多人共用一台机器人、想按会话分开计费时，才用会话专用 key：`/qweather key 设置` 跟着分步引导走。

### 1. 绑地址

```
/qweather 地址 加 39.90,116.40 名称=公司
```

> 坐标从地图上右键复制，度分秒也行：`/qweather 地址 加 39°54'0",116°24'0" 名称=公司`
> 加完会自动反查行政区，显示成 `公司｜示例市·示例区（39.90,116.40）`，预警按该区县精确匹配。

### 2. 早上 8:00 的全量日报

```
/qweather 推送 加 每天 08:00 内容=全部 日=工作日
```

### 3. 晚上 21:30 的复盘（不含实况）

```
/qweather 推送 加 每天 21:30 内容=全部除now 日=工作日
```

> `内容=全部` 是 8 项全要，`全部除now` 是去掉实况那 1 项，`全部-now` 也行。

### 4. 雨雪提醒

```
/qweather 雨雪 开
/qweather 雨雪 清时段
/qweather 雨雪 加时段 工作日 08:00-12:00
/qweather 雨雪 加时段 工作日 13:00-21:30
/qweather 雨雪 提前 10
/qweather 雨雪 间隔 30
```

默认是「全天 07:00-23:00、提前 60 分钟、轮询 10 分钟」，所以要先清时段再加自己的——
**清空等于全天可提醒**，不清就会在半夜也提醒。

### 5. 灾害预警

```
/qweather 预警 开
/qweather 预警 清时段
/qweather 预警 加时段 工作日 08:00-12:00
/qweather 预警 加时段 工作日 13:00-21:30
/qweather 预警 间隔 60
/qweather 预警 等级 黄
/qweather 预警 变化 开
```

- `等级 黄`：黄色及以上才推（蓝/白不打扰）
- `变化 开`：同一条预警等级升高**或降低**都再推一次。降温转黄说明在缓解，也该知道
- `间隔 60`：预警变化慢，1 小时一次足够，比雨雪的 30 分钟省一半请求

### 6. 额度推送

> ⚠️ **先开控制台权限，否则这一步一定失败。**
>
> 额度功能走的是控制台 API，默认全部关闭。去「控制台 → 项目管理 → 点开项目 → 凭据 →
> 下滑到**控制台权限**」，四项都要勾，后两项还得在下拉里选中具体对象：
>
> ```
> 财务和费用
>   ☑ 允许访问财务汇总数据
> 指标和统计
>   ☑ 允许访问请求量汇总统计
>   ☑ 允许访问指定项目的请求量统计   [ 选你的项目 ]
>   ☑ 允许访问指定凭据的请求量统计   [ 选你的凭据 ]
>                                       [ 保存 ]
> ```
>
> 只勾「汇总统计」是不够的，接口会继续返回 `403 Security Restriction`。

```
/qweather 额度推送 加 每天 21:00 日=工作日
```

额度是**按会话**存的，不挂地址；推送时用本会话的 key（没设过专用 key 就用系统默认）。

加完先发一次 `/qweather 额度` 试通，能出余额和请求量才说明权限对了。

### 7. 验收

```
/qweather 设置
```

应该看到两条推送规则、雨雪两个时段、预警 60 分钟/黄色、额度 1 条，和上面表格一致。

```
/qweather 成本
```

估出每月请求量和花费（见下节）。

## 三、跑起来是什么样

装了 Playwright 的话，每条推送后面还会跟一张图片（先文字、后图片，两条消息）：

```bash

```

没装就只有文字，不影响任何功能。下面是文字版。

实况：晴 21.8°C　体感 16.8°C

后天：8°~16°　少云转晴
11-02：6°~16°　晴
日出 06:36　日落 17:13
空气：AQI 102 轻度污染（首要 PM 10）
```

雨雪提醒（只在设定时段内才会出现）：

```
☔ 降水提醒：公司·示例区 预计 15 分钟后开始
小雨，预计持续约 40 分钟
```

预警推送长这样（括号里是等级变化方向，同一条预警第二次推才带）：

```

```

降级也会推，箭头变成 `↓ 橙色→黄色`——说明在缓解，同样值得知道。

## 四、每月要花多少

按 31 天、其中 18 个工作日估算：

```
【公司】
  1. 每天 08:00〔仅工作日〕｜全部内容　约 18 次/月 × 7 = 126 次
  2. 每天 21:30〔仅工作日〕｜全部除实况　约 18 次/月 × 6 = 108 次
  雨雪轮询 每 30 分钟　约 450 次/月
    （每轮查一次分钟降水）
  雨雪预筛 逐时预报　约 234 次/月
    （平均每天 7.5 小时落在时段内（已按工作日折减），逐时有 1 小时缓存）
  预警轮询 每 60 分钟　约 225 次/月
    （预警列表全局共享，多地址会摊薄）
  预警详情（列表命中才查）　约 225 次/月 × 0.05 = 11 次
    （按每 20 轮命中 1 次估，实际取决于有多少预警）

【本会话】
  1. 每天 21:00〔仅工作日〕　约 18 次/月 × 2 = 36 次

合计：约 1,190 次/月
成本：0.00 元/月（每月前 50,000 次免费，还剩 48,810 次余量）
```

几个要点：

- 「全部内容」按 **7 次**算，不是 8 次——日出日落是一次请求里同时拿的
- 雨雪的大头是轮询：30 分钟一次 × 时段内的小时数。嫌多就把间隔调到 45~60
- 预警列表全局共享且有 5 分钟缓存，加地址不会成倍涨
- 官方「天气和基础服务」每月前 5 万次免费，超出后每万次 7 元（0.0007 元/次，累进）
- 以上**不含手动发指令查询**的次数

## 五、为什么这么设

1. **早报给全量、晚报去实况**：出门前要当下温度、穿衣建议和能见度；晚上只需要明天的
   预报和空气质量，实况那行已经过期了，还白花一次请求。
2. **全挂工作日**：周末和法定假日不看公司天气；调休上班的日子算工作日（插件自带节假日日历，
   会自动抓次年安排），不用年年手动改。
3. **雨雪提前 10 分钟**：分钟级降水本身有 10 分钟粒度，提前太多不准，太少来不及。
4. **时段拆成 08-12 + 13-21:30**：中午 12:00-13:00 是吃饭时间，提示价值低；21:30 以后
   不打扰。两段分别加，比一整段更精确。
5. **预警等级升降都提醒**：只看升级会漏掉「解除」和「降级」，而解除恰恰是最该知道的消息。

## 六、常见调整

| 想做的事 | 命令 |
| --- | --- |
| 再加一个地址（家里） | `/qweather 地址 加 39.95,116.30 名称=家`，然后 `/qweather 地址 用 家` 切过去再配推送 |
| 只看周末推送 | `/qweather 推送 加 每天 09:00 日=休息日` |
| 每天推、不分工作日 | 把规则里的 `日=工作日` 去掉，即 `/qweather 推送 加 每天 08:00 内容=全部` |
| 降水只提醒开始 | `/qweather 雨雪 结束 关` |
| 预警不要太吵 | `/qweather 预警 等级 橙` |
| 看/删某条规则 | `/qweather 推送`（列出编号）、`/qweather 推送 删 2` |
| 临时查一次 | `/qweather 天气`，或 `/qweather 天气 地址=2` |
